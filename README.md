# JavaScript Practice 🚀

A collection of my **JavaScript learning, practice programs, and concepts**.
This repository is created to build a strong JavaScript foundation for **React Native, backend development, and modern web development**.

## 📚 Topics Covered

### JavaScript Basics

* Variables — `var`, `let`, `const`
* Data Types
* Operators
* Type Conversion
* Conditional Statements
* `if`, `else if`, `else`
* Ternary Operator
* Loops

  * `for`
  * `while`
  * `do...while`
  * `for...of`
  * `for...in`

### Functions

* Normal Functions
* Arrow Functions
* Parameters & Arguments
* Return Values
* Callback Functions
* Higher-Order Functions
* Default Parameters

### Arrays

* Creating & accessing arrays
* `map()`
* `filter()`
* `find()`
* `findIndex()`
* `forEach()`
* `some()`
* `every()`
* `reduce()`
* `includes()`
* `slice()`
* `splice()`

### Objects

* Object creation
* Accessing properties
* Object methods
* Nested Objects
* Object Destructuring
* Spread Operator
* Rest Operator
* Optional Chaining

### Modern JavaScript (ES6+)

* Template Literals
* Destructuring
* Spread & Rest Operators
* `let` & `const`
* Arrow Functions
* Default Parameters
* Optional Chaining `?.`
* Nullish Coalescing `??`
* Modules — `import` / `export`

### Asynchronous JavaScript

* Callbacks
* Promises
* `async` / `await`
* `try...catch`
* Fetch API
* JSON
* API Requests

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/wthstranger/javaScript.git
```

Go to the project:

```bash
cd javaScript
```

Run a JavaScript file using Node.js:

```bash
node filename.js
```

Example:

```bash
node basics/variables.js
```
